# 中国及港澳台

目的地是中国大陆、香港、澳门或台湾时阅读。这些规则会改变预订、地图、支付和假期判断。

## 来源

等级和冲突处理见 [research-playbook.md](research-playbook.md)。本地常见顺序：

1. 官方：文旅局、景区/博物馆官网、轮渡公司、12306、中国气象局 / 当地气象台、市政府交通/停车、国家移民管理局（出入境）
2. 地图和评价：高德优先，然后大众点评 / 美团
3. 预订：携程、飞猪、美团酒店 — 用来核对店名和价格带，门票不以它们为最终依据
4. 官网点名的微信公众号 / 小程序做分时票

中国行程不要把 Google Maps 当主地图。开放时间、路况、步行路线常常是旧的。

## 假期和人流

每次都查 `{年份} 节假日调休`。不要背去年的调休。

春节、国庆、五一、不少暑假周末：默认会订空、酒店 2–4 倍价。热门票 / 海景房 / 船票放进必订。

景区最晚入园常常是 16:00–17:00，不是闭园时间。索道和园内摆渡比大门停得更早。

博物馆周一闭馆很常见，要核实。

## 票和证件

很多大陆景区是实名 + 分时预约（身份证 / 护照）。写清渠道：官方小程序、文旅预约，或携程作备份。

旺季不要告诉人故宫、热门博物馆、岛屿船票「窗口随买」。

联票 vs 单票：行程里真的会用到那些项目才推荐联票。

**优惠票**（带娃、带老人、学生）：

- 同一趟行程里规则也不统一：有的按身高（1.2 / 1.4 m），有的按年龄，有的两者择一。写清按哪个依据，不要假设
- **免票不等于免预约**：很多景区的免费票同样要实名预约，热门馆一样抢
- 常见分档：学生（学生证 / 国际学生证）、60 / 65 / 70 岁老人、军人、残疾、学龄前
- 用优惠票入园一般要查证件，提醒带原件；境外学生证不一定通用
- 预算按「全价 / 优惠价」两列算，不要把免票默认进总额

## 铁路、飞机、市内

- 写全站名（北京西 vs 北京南，上海虹桥 vs 上海站）。站错了，当天就毁了。
- 高铁：12306 是准绳；携程只是镜像。写「席别 / 时刻以下单页为准」。
- 大站预留 30–45 分钟进站。
- 一线城市默认地铁 + 步行。行李、深夜、带老人再用出租/网约车。
- 网约车常常要中国手机号。给访客准备地铁/出租车备选。
- 城际大巴存在，但除非用户自驾或铁路不到，否则是第二选择。

## 开车

**先查限行，再排骨架。** 限行决定「这一天能不能开车进城」，比停车更硬：违反了是罚款 + 扣分，不是不方便。

- 外地牌限行各城不同：北京（进京证 + 工作日尾号轮换）、上海（高架快速路时段限行）、广州 / 深圳 / 杭州 / 成都等另有规则 —— 按**出行当月**的当地交管局公告查，不要背旧规则
- 尾号 / 单双号轮换经常调整，节假日和调休日是否停限行要单独核实
- 有些景区要**预约通行**（名额制）才能开车进入；没约到就改地铁 / 接驳或停外围
- 写进攻略的应是：受限时段、受限区域、官方查询入口；不要给「怎么绕开限行」的做法
- 限行覆盖出发 / 返程时段时，把车停外围（P+R）或改高铁 + 市内交通，不要硬闯
- ETC、高速名、过桥费、易堵段
- 老城和海岛：先确认能不能开车；否则停车再步行
- 节假日景区停车场上午就满 — 写早到，或把车放下
- 小型客车高速公路免收通行费的节假日范围：以交通运输部当年公告为准，不要按去年日历硬套
- HTML 自驾：私人本地页有包外或兼容配置的 jsKey + 安全码时可接 AMap 2.0；分享版或无凭据时用高德 URI + SVG 路线示意图。飞机 / 高铁 / 火车不要地图，列已核实票价或官方查询入口。见 maps.md / live-data.md
- 限高、充电桩：用户说了车型 / 能源才当筛选条件

## 住

- 民宿 vs 酒店：民宿可能没有电梯、发票或 24 小时前台。老人 / 深夜抵达 / 要发票时标出来。
- 自驾时停车是筛选条件，不是脚注。漂亮但没车位的巷子民宿，除非他们接受附近车库，否则淘汰。
- 海景房：核对哪一侧真的朝水；「海景」经常是营销词。

## 吃和支付

- 人均带取自大众点评 / 美团，不要虚构精确到个位的人均
- 出名早餐和老字号要写排队或预约
- 坑：先吃后称、景区门口托、茶艺强制消费、黑车
- 支付：微信 / 支付宝为主。现金是备份。外卡常常刷不了 — 如果同行人不用微信/支付宝，写进当地注意
- 即使没人提，也留一家清淡 / 素食备选

## 香港 / 澳门 / 台湾

不是「另一座大陆城市」：

- 港澳：签注 / 通行证。指向国家移民管理局页面；不要猜剩余签注次数
- 香港：MTR、八达通 / 交通码，Google Maps 能用，很多店接受卡 + 支付宝HK / WeChat HK。自驾是左行
- 澳门：半岛/路氹之间靠船和公交；赌场区夏天走路很长
- 台湾：需要入台证时只指向官方；悠游卡、Google Maps、现金+卡。不要假设微信处处能付
- 跨境火车和轮渡有末班，误了会困住。放进必订 / 当天注意

## 天气规律（要查，不要背）

- 华南夏天：高温 + 台风。准备室内日
- 江南梅雨：博物馆、有顶街道、多留空档
- 北方冬天：日照短、冰雪路滑
- 高原 / 西北：海拔、干燥、昼夜温差大 — 见 modes.md
