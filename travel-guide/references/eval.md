# 回归案例

改完 skill 之后才读这份，抽查实际决策与交付物；做攻略时不要读。表中要点是行为证据，不能只匹配关键词或标题。天气数字、价格、签证和开放时间须能追溯到适用日期与来源。

| id | 请求 | 必须出现 | 必须不存在 |
|---|---|---|---|
| 01 | 杭州周末 2 天，有日期且户外为主 | 精简档；天气节中的预报只对应出行日期，缺日就标缺；`city_trip`（若 HTML）；已核实交通价或官方入口；无 `#map` | 其他日期气温冒充预报；Driving；补能；驾车 URI |
| 02 | 上海 3 天，地铁 + 步行 | `city_trip`；天气按实际影响加入；交通价有来源或官方入口；页头交通方式正确 | `AMap.Driving`；`#map`；驾车全程按钮；假连线 |
| 03 | 杭州→舟山自驾 3 天 | `self_drive`；`fullNav`；`coordinateSystem=gcj02`；停靠表 | 境外地图；把车程排除在负荷外 |
| 04 | 北京亲子 3 天，孩子 5 岁 | 午睡/排队；低强度备选 | 背靠背分时票 |
| 05 | 西安 3 天带老人 | 少台阶；每天一个主活动 | 连续爬山；过紧换乘 |
| 06 | 东京 5 天两人总预算 3000 元 | 直说不可行；最低可行方案 | 造假穷游；假装预算够 |
| 07 | 江南 7 天三城，要求逐日详细 | 按用户要求逐日写交通与时段；按复杂度使用 Standard/Deep 研究并核实必订与末班交通 | 因超过 7 天擅自压成每城几条；无来源的换乘规则 |
| 08 | 舟山海岛 2 天 | 末班船；停航备选 | 假设天天通航 |
| 09 | 已订某酒店，只要改 D2 | 酒店锁定；只改冲突 | 重搜住宿；重排全程 |
| 10 | 只要导出已有行程的 HTML | 对话摘要 + 文件；`#trip-geo` JSON 可解析且 `version=1.4`；天气依行程需要加入；ID 完整 | `{{`（含脚本内残留）；样例点名；模式与交通不一致；`document.write` |
| 11 | 大阪落地，奈良京都电车 | `city_trip` / `multi_city_transit`；Google search | 境外驾车 `/dir`；Driving；自驾路线；高德地图脚本 |
| 12 | 飞机落地杭州后租车 2 天 | `mixed`；`drive:true` 视图带 `views[].nav`；**无** `fullNav`；停靠节显示；非自驾段不画驾车 | 整份都出停靠补能；把航班画成驾车 |
| 13 | 有 Key 的私人本地杭州自驾 HTML | 钥匙来自包外配置或兼容文件；`{{AMAP_LOADER}}` 已替换；`self_drive` 插件含 `AMap.Driving`；安全码写在地图脚本之前 | 残留占位符；运行时 `document.write`；聊天里打印 key |
| 14 | 无 Key 的同一请求 | 走 SVG 路线示意图 + 高德 URI；文件里无 `webapi.amap.com/maps` 脚本 | 编造 Key；空白地图 |
| 15 | 东京 4 天，地铁，HTML | `mapRenderer=svg`、`linkProvider=google`、`coordinateSystem=wgs84`；Google Maps search 链接 | `webapi.amap.com`；Driving；高德全程按钮；Google Maps JS API |
| 16 | 飞机 + 高铁 + 地铁，无自驾（`mixed`） | `mixed`；无 `#map`；飞机/高铁交通表有来源或官方查询入口；天气按日期与行程需要加入；停靠节隐藏 | Driving；`#map`；停靠补能；`fullNav` |
| 17 | 上海飞杭州 + 杭州租车 2 天 | `mixed`；至少一个 `drive:true` + `lineMode=route` 视图；Driving 插件；该段 `views[].nav`；非自驾段只标记 | 全程 `fullNav`；非自驾段画驾车 |
| 18 | 数据损坏（`markers:["abc"]`，points 无 abc） | 生成前 QA 拦下并修正 | 静默吞掉后交出少点的文件 |
| 19 | 某天排了 5 个半小时的锚点 + 2 小时车程 | 砍掉边缘锚点或挪到别天；每天留缓冲 | 压缩缓冲或写「时间紧一点也能走」 |
| 20 | 舟山 2 天，末班船 17:30 | 倒推「最晚 16:30 前必须开始返程」并写进当天 | 末班船之后仍排安排 |
| 21 | 自驾单日 380 km | 当天锚点 ≤ 1，或改分段过夜 | 排 3 个景点 |
| 22 | 改需求：加一天 | 说明重算了骨架/住宿晚数/预算，哪些沿用 | 整份重搜重写 |
| 23 | 改需求：换目的地 | 明确全部骨架和检索都重做 | 沿用旧城市的店和票 |
| 24 | 「行程太满了，轻松点」 | 按 order 砍锚点并说明砍了什么 | 整份重排；或只加一句「可以少走一点」 |
| 25 | 景区票价查不到 | 写清未核实、给官方售票入口，预算列待确认；必要时调整当天安排 | 用同类景区区间代填；把未知价格写成已确认 |
| 26 | 打印场景 | 打印样式生效：无导航/地图 iframe，链接附 URL | 打印出一片深色块或空白地图 |
| 27 | 北京自驾 3 天（外地牌） | 先查进京证 / 尾号限行，写受限时段与官方查询入口 | 假设随时能开车进城；教怎么绕开限行 |
| 28 | 上海亲子 3 天，孩子 1.35 m | 优惠票按身高还是年龄逐馆核实；免票也写要不要预约 | 一个年龄或身高套所有景区；把免票默认进预算 |
| 29 | 交一份 HTML（任意） | 已跑 scripts/validate_html.py 且无 FAIL | 交付带占位符 / ID 断裂 / 与 htmlMode 不符的文件 |
| 31 | 重复 point ID | `points` 里同一个 id 出现两次 → 被拦下并指出重复项 | 静默交付（壳子按 id 覆盖，后面的点消失） |
| 32 | 重复 view ID | 同一页签 id 重复 → 被拦下 | 静默交付（点页签行为不可预期） |
| 33 | point 缺 lon/lat | 缺坐标或坐标越界 → FAIL；无坐标的点改为只写正文表格 | 交付后 SVG 算出 NaN、示意图空白 |
| 34 | mixed 视图 `drive:true` + `lineMode:none` | 判为配置冲突 → FAIL | 通过（实际既不加载 Driving 也不显示停靠） |
| 35 | `self_drive` 缺 `fullNav` | 判为 FAIL，补上全程导航 URI | 交出 `href="#"` 的「打开全程导航」空按钮 |
| 36 | 境外 / 混合行程的 SVG 线型 | 非自驾段画虚线（`stroke-dasharray`），与 AMap 侧一致；真实壳子文件不误报 | 非自驾段画成实线，看着像能开车；或误判壳子 JS 里的 AMap 调用 |
| 30 | 东京 5 天，含红眼航班 | 当地报警急救 + 12308；护照丢失三步 | 只写「注意安全」 |
| 37 | 和风连不上，气象台有出行日数据 | 使用对应日期和地点的官方数据，标来源与查询日 | 编气温；使用别的日期的卡片 |
| 38 | 只说「帮我规划」，没给目的地 | 一轮收集去哪、从哪出发、日期天数、人数、自驾或飞机/高铁/火车、预算、节奏；然后停住 | 先交默认 3 天两人行程；把公共交通理解成市内公交；拆成多轮连问 |
| 39 | 「杭州国庆 3 天，两人高铁」 | 直接规划；写明其余默认（舒适、适中等） | 再发收集表盘问 |
| 40 | 杭州周末 2 天（普通「做攻略」） | 通常 Fast；批量研究并核最终声明；事实有冲突时可升档或删具体断言 | 为备选越搜越多；因参考量已满而填无来源数字 |
| 41 | 住宿短名单，没说「认真选酒店」 | 1 主选（打开 1 页）+ 1 备选只确认存在和价格带 | 备选再开官网 + 预订页交叉验证 |
| 42 | 只要导出 HTML，未指定风格 | 只转换已核实事实；默认杂志版但图片可省；关键事实缺证据则回到内容核查或删断言 | 为装饰补店、编价格；只交失去逐日信息的壳子 |
| 43 | 天气源均失败，且无法取得出行日数据 | 天气有关时用 `data-weather-status="unavailable"` 说明缺口、官方入口和复核时间 | 凭空手写气温卡；用近期天气冒充出行日预报 |
| 44 | 自驾 HTML，`fullNav` 写成 `hello` 或 `https://example.com` | `validate_html.py` FAIL | 交付带空壳/垃圾导航按钮的文件 |
| 45 | `lineMode=route` 且 path 为空或只有 1 个点；mixed 自驾段 `nav="hello"` | `validate_html.py` FAIL | 静默交付没有路线的路线页，或点不开的导航 |
| 46 | 用户说「导出 HTML」，没提风格 | 默认杂志版：清楚的封面、主线、日卡与住宿信息，合规图找不到可用渐变 | 必须再问视觉风格；为封面搜图而耽误事实核实 |
| 47 | 用户明确要极简打印 HTML | `<body data-guide-style="print">`；无装饰图也可通过；日期、来源和链接仍清晰 | 杂志版 WARN 强迫补图；打印深色背景或空白地图 |
| 48 | 行程有 5 个酒店 / 景点坐标，地图只放城市中心 3 个点 | 酒店、当天主景点、点名服务区的坐标都进 `points`，地图能看出当天怎么走 | 只放城市中心；为了补点数假造坐标；缺坐标的点硬塞进 `points` |
| 49 | 给 HTML，已有事实完整但没有合规图片 | 不为装饰再搜图；可用渐变 / `.art-fig`，极简版可完全省图 | 留空白 `<figure>` 裂图；热链酒店 CDN |
| 50 | 杭州 3 天普通完整档 | 按关键事实数量选档，通常 Standard；核心 / 收费 / 必订景点做官方核实，非核心不编具体开放规则 | 为格式完整逐个搜无关细节；为了维持 Fast 而省略必需核实 |
| 51 | Fast 档研究中发现多项必订和换乘硬缺口 | 自动升 Standard 并定向核查，或调整行程、删未核实断言 | 为满足 Fast 轮次上限而把未知规则写成事实 |
| 52 | 常规研究量接近目标值 | 停止新增候选和图片；若存在来源冲突或会改变结构的缺口仍核实或明确披露 | 再搜第 3 个餐厅；因预算忽略冲突 |
| 53 | 普通攻略检索到中途 | 内部记录研究范围和已核事实；已有足够依据就收束候选池 | 向用户展示无关计数器；研究量未用完就强行凑候选 |
| 54 | HTML validator FAIL，原因是缺坐标 | 先修结构 / 删字段 / 改示意图；只有原行程关键坐标缺失才定向核实 | 因 FAIL 重搜酒店、餐厅或图片 |
| 55 | HTML 核心事实已核实、图仍未找到 | 不再为装饰搜图，直接用渐变或极简版 | 为图片扩张研究；留空白图位 |
| 56 | 研究结束时一间可替换餐厅的营业时间未核实 | 不把营业时间写成事实；标为可替换建议并给商家入口 | 写「常规 09:00–17:00」之类的通用时间 |
| 57 | 行程结构和最终硬声明都有可信依据 | 停止研究并写作 | 为用满预算继续扩张候选 |
| 58 | 已用 S 级官网确认某景区票价 | 直接写进攻略，带来源和查询日期 | 再开第 2、第 3 个站点「交叉验证」；说「只有一个来源不保险」 |
| 59 | 评估「要不要把 5 家酒店都列出来」 | 每城 1 主 + 1 备；已有可用选项就不重复搜同类 | 搜 10 家酒店比价后再搜 10 家餐厅 |
| 60 | 搜「杭州景点」时发现一个没听过的小众点 | 不自动加入研究范围，除非它直接解决一个尚未解决的关键需求 | 搜 A → 发现 B → 搜 B → 发现 C 的链式扩张 |
| 61 | 普通「完整档」3 天攻略 | 只深核核心 / 收费 / 必订的核心实体 | 为「完整档」把每个餐厅 / 景点 / 酒店逐一深度研究 |
| 62 | 天气查询失败 | 如天气相关，查官方入口；无出行日数字就说明缺口与复核时间，主线不重研 | 因天气失败重写行程；编气温卡 |
| 63 | 要 HTML，图片搜了 1 次没找到理想图 | 转用 `.art-fig` 氛围块 | 反复搜图直到满意 |
| 64 | validator 报 FAIL（缺坐标） | 修结构、删无效字段或改示意图；若原行程确缺关键事实才定向核实 | 为补视觉点数而搜索无关酒店餐厅或假造坐标 |
| 65 | 搜索结果页已含足够可信的低风险信息 | 可直接用；价格、开放时间、政策仍按官方来源要求核实 | 明明已有可信结果还重复打开；把聚合摘要当签证依据 |
| 66 | 用户只要酒店短名单，未给出行日期 | 核实具名酒店与片区；不强加天气、逐日行程和交通表 | 空天气卡、假设日期、无关打包清单 |
| 67 | 2026-10-13 出发日与脚本可用天气记录不一致 | 只写确切匹配日期；`coverage.missingDates` 披露缺口 | 其他日期卡片标为出发日 `forecast` |
| 68 | 远期行程，天气脚本只给近期参考 | 明确「近期参考，非出行日预报，也非历史气候」并注明参考日期 | 把近期预报写成目标月份气候数字 |
| 69 | 国内自驾 HTML 准备公开分享，已有地图 Key | `mapRenderer=svg` + 高德导航 URI；文件不含个人地图凭据 | 因本地有 Key 自动嵌入 AMap JS |
| 70 | 境外行程问能否免签，只给了目的地 | 收集会改变适用性的护照国籍、居留身份、过境、目的和日期；暂给官方入口 | 默认中文用户持中国护照；一句「以官网为准」后仍下适用结论 |
| 71 | 用户要极简打印 HTML | `data-guide-style="print"`；清楚的日期、来源、链接和纸面布局 | 因没有封面图而强制 WARN 或多搜图片 |
| 72 | 发布新版本 | 发布清单和 ZIP 只含白名单；无 `.playwright-cli`、单次行程脚本和真实密钥；解压后自测通过 | 把测试快照或本机私人配置装进正式包 |
