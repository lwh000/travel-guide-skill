# 出境

行程跨边境，或用户问签证、eSIM、时差、插头、保险时阅读。

不要代填签证、入境表，也不教人谎报出行目的。

## 地名、地址、时刻的写法

中文行程落地后仍要对着当地牌子、车票、地图找路，只写中文译名会找不到。

- 地点名：**中文 + 当地原文**，如「浅草寺（浅草寺 / Sensō-ji）」「老佛爷百货（Galeries Lafayette）」
- 地址、站名、酒店名：一律保留原文，中文只作辅助。问路、打车、填入境卡都用得上原文
- 车次 / 航班：写原文编号和全名，如「成田机场第 1 航站楼 Narita Terminal 1」
- 营业时间：当地时刻，同时标清时区有变动的日子（夏令时切换周）
- 搜索链接用原文，不要用中文译名去搜（Google Maps 对中文译名命中率差）

中文译名有多个版本时（如「圣托里尼 / 桑托里尼」），以原文为准，中文只给一个常用译名。

## 证件

- 先确定护照国籍、居留/签证身份、出发与过境地、目的地、旅行目的和出行日期；这些信息会改变适用规则。缺关键信息时只给对应官方核查入口，先不下免签或过境结论。
- 护照有效期、签证 / 免签 / 过境 / ETA / 电子签：查目的地和过境地的使馆、移民或边检官方页面。写清适用身份、查询日期、链接与需再次核查的时间；不套「一律 6 个月」等经验值。
- 不要猜过签率、「容易过」或边境跳签
- 回程票、住宿地址等入境材料按这次适用的官方清单提示，别把常见经验写成统一要求
- 护照丢失：按当地警方及本人国籍的驻外使领馆官方流程处理；出行前把证件、签证和保单备份到安全可访问的位置
- 保险：一行，医疗 + 延误值得买，不要推销具体产品

## 落地 24 小时

- 抵达日按半天。红眼航班后不要排 6 个博物馆
- 时差：白天出门见光、晚饭清淡一点；除非他们坚持，不要把高风险分时票排在 08:00
- 入境 + 行李 + 去酒店常常 2–3 小时，要算进去
- 确认机场（成田 vs 羽田，戴高乐 vs 奥利，盖特威克 vs 希思罗）

## 钱、电话卡、插头

- 这个国家用卡 / 现金 / 手机支付，一行说清；现金国家补 ATM 注意
- 小费：一行，或「一般不用付小费」
- eSIM / 机场卡 / 漫游：给检索入口，不要假优惠码
- 插头类型（C / G / A / I …）以及是不是除了 USB 还要转换器
- 自来水：能喝 / 不能喝 / 只烧开 — 只在会改变打包时写

## 怎么移动

- 先查官方铁路/地铁。日票只有行程真用得上才推荐
- 不要默认日本 JR Pass、欧铁通票或机场快线 — 先跟点对点票粗算
- 晚饭晚要看末班车
- 行李：退房日硬币柜 vs 酒店寄存
- 航空行李额：廉航常不含托运，超重费可能比票贵；写清含几件、多少 kg —— 它直接决定打包和购物额度
- 网约车 vs 出租 vs 公交按城市写。租摩托：头盔、保险、下雨，以及对第一次来、交通乱的城市不是默认选项
境外自驾不在本 skill 范围。如果用户主动提出，只给官方驾照 / 租车 / 交通规则入口，不排自驾路线。

## 地区（只读对得上的）

**日本：** IC 卡常见；不少小店仍收现金——出行前核当地支付。小餐馆休息不规律，热门晚饭要预约，进屋脱鞋，不要默认 JR Pass。

**韩国：** T-money 很常见，出行前核是否仍适用；卡很普及，周末著名烤肉/咖啡要预约。

**东南亚：** 热 + 雨，有 Grab 就用，寺庙着装，摩托车要小心，季风会取消跳岛船。

**欧洲：** 周日 / 周一闭馆很常见，仍要核该馆当天；博物馆分时，火车 vs 廉价机票（机场耗时可能吃掉「很近」）。

**美国 / 加拿大：** 小费，税另加。纽约、旧金山、波士顿、芝加哥、多伦多、温哥华等市中心先看公交/步行是否够用。

**澳大利亚 / 新西兰：** 距离长、阳光强；长途交通要单独核。

**中东 / 北非：** 着装、斋月时间变化、高温，官方旅行提示点到为止。

## 安全与底线

- 只给高层次提示并链到官方来源。不要渲染恐怖
- 当地报警 / 急救电话写进攻略；境外再加中国领事保护 **12308**（含 +86-10-12308）。只写「注意安全」等于没写
- 不要推荐非法民宿、禁区或未申报工作
- 野生动物、海拔、清真寺/寺庙规则放进当地注意
- 药品：原包装自带，当地规定自行核对

## 相对国内多带什么

护照、复印件、转换插头、处方药、eSIM、一张境外真能刷的卡。完整清单见 packing.md。
