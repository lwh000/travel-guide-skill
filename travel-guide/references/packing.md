# 打包

只写这次气候和交通真正需要的。十行通常够，二十行封顶。

## 按天气

| 情况 | 加 | 不要 |
|---|---|---|
| 热 / 湿 | 防晒、浅色透气、补电解质、伞 | 厚牛仔叠穿 |
| 梅雨 / 雷阵雨 | 折叠伞、快干鞋、行程里已有室内备选 | 只带一双绒面鞋 |
| 台风季 | 多一个室内日、停航备选 | 坚持跳岛 |
| 冷 / 冰雪 | 分层、防水、防滑鞋、按日照排行程 | 只穿棉 |
| 高海拔 / 干燥 | 唇膏、防晒、第一天放慢 | 接风酒喝很猛 |
| 海滩 / 海岛 | 需要时用对珊瑚友好的防晒、防晒衣、礁石滩再加溯溪鞋 | 两晚海岛却带一箱晚装 |

## 按交通和同行

- **自驾：** ETC、充电线、纸质导航备份、水、小停车场现金
- **高铁：** 小件放在好拿的位置；不是露营包
- **徒步：** 穿过的鞋、雨壳、凌晨出发才手头灯、创可贴
- **亲子：** 备用衣服、零食、助眠小物；推车还是背带在住宿节定
- **长辈：** 常用药、额外休息、少换衣服、舒服的鞋

## 出境加项

- 插头类型、eSIM 或漫游、一张能用的卡、护照复印件
- 处方药带原包装
- 没有要求完整收纳清单时，不要凑「颈枕、眼罩、十双袜子」

## 格式

按 证件 / 衣服 / 鞋 / 装备 / 药品 分组的短清单。HTML 里做成勾选。
