# 图片与媒体

HTML 攻略才读。对话里的 Markdown 不要嵌大图。

## 允许

- Wikimedia Commons 缩略图（约 800–1200px，`thumb.wikimedia.org` 或 `upload.wikimedia.org`）
- 景区 / 文旅官网许可清楚、可热链的图
- 用户自己提供的本地图

## 只放景观图，不放人（硬规则）

攻略配图一律用**景观、建筑、街景、自然、器物、夜景**这类没有主体人物的图。

**禁止**：以人物为主体的照片 —— 人像特写、工匠 / 店员 / 表演者特写、游客合影、带正脸的路人、儿童特写、婚纱 / 写真。哪怕照片质量好、授权干净、拍的就是行程里的场景，只要是「人在画面中心」就不要用。

判定方法（看图时直接问自己）：

1. 画面里最大、最清晰的元素是不是人？是 → 换图。
2. 把人物去掉后这张图还剩多少可看的内容？几乎不剩 → 换图。
3. 人物只是远景 / 剪影 / 模糊陪衬，用来体现尺度（例如广场上的小小人影、街景远处的人流）→ 可以用。

替换优先级：同一地点的**建筑外景 / 全景 / 街景 / 俯拍** > 局部细节（屋檐、砖墙、器物、招牌、展陈）> 空镜自然。

**只在没有可用景观图时才降级**：换下一个候选，或改用壳子渐变 / `.art-fig` 氛围块；不要为了「有张图」而接受人像。

这条同样适用于封面、日卡、住宿卡和任何插图位。选图时逐张看图确认，不要只看文件名或搜索摘要。

## 禁止

- 携程 / 美团 / 飞猪酒店 CDN、相册、水印房型图
- 抄用户旧 HTML 里的图床或 1MB 相册 JSON
- 同名地点配错省市区（另一座山、另一片海滩、另一个岛）
- 没有出处的网图、秘密机位航拍
- **以人物为主体的照片**（人像特写、工匠 / 表演者特写、游客合影、正脸路人、儿童特写）—— 见上节

## 每城怎么选

图片是杂志版的可选视觉增强，不阻塞正文研究；用户要极简或打印优先时可以完全不用图。需要图片时在研究阶段一次获取，HTML 阶段不为装饰再搜。图片搜索的参考量以 [research-playbook.md](research-playbook.md) 的「图片来源与搜索」为准。

- 未指定视觉风格的 HTML 默认杂志版，但先完成核心事实。需要实拍图时可在研究阶段做 **1 次** Commons 批量搜索，取页头封面 + 每个过夜城各 1 张，上限 6 张；用户指定极简/打印版则跳过。
- 只在对话里给行程、不写 HTML：不要搜图。
- **图片搜索是一次性动作。不得因为找不到理想图片而反复搜索。**
- HTML 阶段不重搜图。研究时没拿到或预算不够，就退到壳子渐变 / `.art-fig` 氛围块，不要为了美观再开一轮检索，也不要留裂图。

**图全找不到时的兜底**：一个字都没有也不影响攻略可用性。页头用壳子自带的渐变 `.hero-bg`；日卡用内联 SVG 氛围块或纯色块 + 地名，不要留 `<img>` 裂图，也不要转而去热链没授权的图。视觉处理见 [html-guide.md](html-guide.md) 的「视觉」一节。

每个过夜城市 1 张，同一片区最多 2 张，一张能看出「这是海边 / 渔港 / 古城」。酒店没有 Commons 真图，就用该片区风景，不要热链酒店官网未授权图。
页头封面优先用全程最有辨识度的那张（海边 / 山口 / 古城天际线）；没有合适图就用壳子渐变 `.hero-bg`，不要硬凑。

**选图时逐张看一眼**：搜到的候选先看画面内容再决定用不用，不要只靠标题或描述下判断；发现自己拿的图是人物特写就换掉。同一天不要用两张同一地标的图（例如 D1 和 D2 都放滕王阁），同片区撞图时换成本片区另一个地标。

没有合适图就用壳子 CSS / 内联 SVG 氛围块，写地名，不要裂图，也不要为每天行程卡再搜图。

每张必须有：

- `alt`（中文，说清地点）
- 图注：地点 · 作者 · 许可（CC BY / CC BY-SA / 公有领域）
- 指向 Commons 文件页或官网的链接

页脚或出处表汇总图片许可。

## 检索

只在**要写 HTML 且尚未进入降级区**时走本节，而且**只走一次**（批量）。计费和上限计入 [research-playbook.md](research-playbook.md) 的预算；已进入降级区就直接用 `.art-fig`。

1. Commons 分类用英文地名 + 省/国家，并核对照片描述里的地点
2. 中文关键词容易命中古籍 `djvu`，要过滤非 `image/*`
3. `prop=imageinfo&iiprop=url|extmetadata|size&iiurlwidth=1200`
4. 读 `LicenseShortName`、`Artist`、`descriptionurl`
5. 批量取图时写成脚本文件再执行（Windows 下内联命令的中文路径会乱码）
