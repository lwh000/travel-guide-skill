手机怎么用（华为 / 安卓 / iPhone 通用）：
  • 把这份 HTML 拷到手机上，用 Chrome、Edge 或华为自带浏览器打开（不要用微信 / QQ 内置浏览器——高德官方明确说明这两个容器无法唤起 App）。
  • 点「打开全程导航」或任一「本段导航」，页面会请求跳转到高德地图 App，起点 / 终点 / 途经点、驾车模式会自动填好，不用手打地址。
  • 跳转成功的前提：手机装了高德地图，且允许浏览器「打开受支持的链接 / 关联应用」。
  • 如果没唤起 App，会自动退回到高德网页版地图，路线一样能看，只是不能在网页里直接开始导航。
